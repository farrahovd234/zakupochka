# ЗакупОчка — публичная летопись

Статический аналитический сайт: **https://farrahovd234.github.io/zakupochka/**

Источник статистики: экспорт истории за 17 сентября 2025 — 7 ноября 2026, время UTC+05:00. 108 241 сообщение, 32 отображаемых авторских имени, 174 редакторских сцены и 63 сюжетные линии.

## Что публикуется

- Агрегаты, графики и краткие описания участников.
- Редакторский пересказ событий и мемов.
- Поиск по публичной летописи.
- Две публичные CSV-таблицы с агрегатами.

Исходных сообщений, адресов, телефонов, оригинальных файлов и приватных вложений в репозитории нет. Часть отображаемых имён заменена. Похожие имена не объединены автоматически. Персонаж или роль в меме не считается биографическим фактом.

## Запуск

Достаточно любого статического HTTP-сервера. Например:

```sh
python -m http.server 8080
```

GitHub Pages публикует корень ветки `main`. Сборка и внешние зависимости не требуются. Все пути относительные, шрифты хранятся локально, внешних аналитических счётчиков нет.
