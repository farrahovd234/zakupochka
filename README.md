# ЗакупОчка — летопись общего чата

**https://farrahovd234.github.io/zakupochka/**

Интерактивный альманах доступной истории за 17 сентября 2025 — 7 ноября 2026, UTC+05:00. 108 241 сообщение, 417 календарных дней и 32 авторских имени.

## Как читать

- **История:** девять глав без временных разрывов; главы связаны с людьми, мемами и событиями.
- **Нити истории:** десять тематических маршрутов через разные эпохи.
- **Хроника:** 174 сцены с коротким описанием, подробной карточкой, характером источника и опорным номером.
- **Люди:** все 32 авторских имени, фильтры, несколько способов сортировки и помесячный след.
- **Мемы:** 63 сюжетные линии с проверенными сценами и отдельно обозначенными поисковыми совпадениями.
- **В цифрах:** дневная активность и 15 месячных агрегатов.
- **Поиск:** главы, люди, сцены, мемы и 76 записей внешнего круга.

Карточки и главы имеют прямые ссылки. Закрытие карточки сохраняет место в списке. Поиск и фильтры отражаются в URL; последняя прочитанная глава и тема сохраняются локально в браузере. Клавиша `/` открывает поиск, `Escape` закрывает карточку.

## Запуск

Сборка и зависимости для работы сайта не нужны:

```sh
python -m http.server 8080
```

GitHub Pages публикует корень `main`. Пути относительные, шрифты локальные. Серверная часть, счётчики и внешние запросы при просмотре не используются.

## Проверка

Для разработки нужны Node.js и Playwright:

```sh
npm ci
npx playwright install chromium
npm run check
npm test
```

На Linux тесты используют `/usr/bin/chromium`, если он установлен; другой путь можно передать через `CHROMIUM_PATH`. Без системного Chromium используется браузер Playwright.

`npm test` запускает временный локальный сервер и проверяет сайт в подпапке `/zakupochka/`. Для проверки опубликованной версии:

```sh
SITE_URL=https://farrahovd234.github.io/zakupochka/ npm test
```

`npm run check` проверяет синтаксис, суммы, непрерывность дней и глав, все внутренние связи и отсутствие полей сырой переписки. Эти проверки дополняют содержательную сверку с частным архивом, но не заменяют её.

## Данные

`data.js` содержит только публичную редакцию. На этапе подготовки сцены и агрегаты сверяются с локальным частным корпусом; он не входит в репозиторий. Исходные сообщения, контакты, адреса, учебные кодовые слова и приватные вложения здесь не публикуются. Адресоподобные имена заменены. Роли и шутки не являются биографическими утверждениями.

Доступны три CSV: месяцы, участники и публичный реестр сцен. Методика и ограничения — в разделе «Как считали» и [VERIFICATION.md](VERIFICATION.md).
